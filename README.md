
# vodafone-customer-churn-


## Overview
This project analyzes customer churn for a telecom company "vodafone " to understand why customers leave.

## Data 
the data is availble in the format of a one clean table With Characteristics:
- **29 columns** 
- **1 row per customer **
- **4 main demnsions**:
  -  customer status
  -  Demographics
  -  Contact informations
  -  Subscription types and charges
  -  **no time dimension**
